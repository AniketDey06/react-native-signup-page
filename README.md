# React Native Signup Page

A clean and modern React Native signup page built with Expo. This project provides a simple and attractive user interface for user registration, including responsive layout, form fields, and smooth styling.

## Features

- Sign-up screen layout with input fields for name, email, and password
- Modern mobile design with a polished look and feel
- Easy to customize for your own app branding
- Built with Expo and TypeScript for fast development

## Project Structure

- `app/` – Expo app entry and layout files
- `src/` – main source code for the signup screen and app UI
- `assets/` – images and icons used in the app

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the Expo development server:

   ```bash
   npm start
   ```

3. Open the app on your device or emulator using the Expo Go app.

## Customize

Update the layout, colors, and form fields in `src/` to match your app design and requirements.
